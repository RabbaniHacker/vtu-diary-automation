# How to Generate Your Custom VTU Internship Diary (.docx)

If your internship was **not** from Edutainer or you are in a **different domain** (such as Artificial Intelligence, Data Science, Cyber Security, Cloud Computing, Python, Java, etc.), you can easily generate your complete customized daily diary in minutes using **Claude**, **ChatGPT**, or **Gemini**.

Once generated, save or download the file as a Word document (`.docx`), drop it into this project folder, and the automation will automatically handle everything!

---

## Method 1: The Master Prompt (Recommended for Claude / ChatGPT)

Open [Claude](https://claude.ai) or [ChatGPT](https://chatgpt.com) and copy-paste the prompt below. **Replace the bracketed items** with your details:

```text
You are an expert technical curriculum designer and technical writer. 
I need you to generate a complete, realistic, day-by-day VTU Internship Daily Diary for my university internship submission.

Here are my internship details:
- Internship Domain / Role: [INSERT YOUR DOMAIN, e.g. Artificial Intelligence & Machine Learning]
- Company / Organization: [INSERT COMPANY, e.g. Infosys Springboard / Internshala / Rooman / Oasis Infobyte]
- Start Date: [INSERT START DATE, e.g. 03 August 2026]
- Total Days / Entries: [INSERT NUMBER OF DAYS, e.g. 110 days or 60 days or 30 days]
- Daily Work Hours: [INSERT HOURS, e.g. 5.5]
- Reference Links: [INSERT REFERENCE URL, e.g. https://springboard.infosys.com/student/learning or relevant documentation URL]

STRICT FORMATTING REQUIREMENTS:
Every single day entry MUST follow this exact format with these exact labels and capitalization:

Day [Day Number] -- [DD Month YYYY]
Internship: [Domain / Role] -- [Company]
Work Summary: [Detailed 1-2 sentence description of technical tasks, implementations, setups, or experiments done on that day]
Hours Worked: [Daily Work Hours]
Reference Links: [Reference Link URL]
Learnings / Outcomes: [1-2 sentences explaining what technical concepts, tools, or best practices were learned]
Blockers / Risks: [1 sentence explaining a realistic technical hurdle, debugging step, or 'No major blockers; focused on understanding the workflow']
Skills Used: [Skill 1], [Skill 2], [Skill 3]

RULES:
1. Every day MUST have at least 3 relevant technical skills in "Skills Used", separated by commas.
2. Skills should match standard industry skills (e.g., Python, Machine Learning, NumPy, Pandas, Data Preprocessing, Scikit-learn, Neural Networks, Docker, Git, SQL, etc.).
3. The progression of daily entries must feel logical, starting from orientation/setup, fundamentals, progressively advanced topics, mini-projects, testing/debugging, and ending with documentation and project presentation.
4. Dates should skip Sundays or run continuously depending on calendar schedule.

Please generate the entries for Day 1 through Day [Total Days].
Then, provide a Python script using python-docx to automatically save these entries into a Word (.docx) file, OR generate the downloadable .docx file directly.
```

## How to Save It as `.docx`

### Option A: Ask Claude to generate the `.docx` directly
In Claude 3.5 Sonnet / Claude 3.7 / Claude 4, simply say:
> *"Now write a python script using python-docx to save all these entries into a file named `my_internship_diary.docx` and provide the file."*

### Option B: Copy into Microsoft Word / Google Docs
1. Copy the text generated by Claude.
2. Paste it into **Microsoft Word** or **Google Docs**.
3. In Google Docs: click **File** $\rightarrow$ **Download** $\rightarrow$ **Microsoft Word (.docx)**.
4. Save the file into your `vtu-diary-automation` project folder!

---

## Method 2: Use the Built-in Generator Script (`generate_diary.py`)

Don't have an AI account or want a diary generated in 5 seconds offline? Use the built-in generator included in this repository:

Run in PowerShell / Terminal:
```powershell
python generate_diary.py
```

It will ask you 4 quick questions:
1. **Domain / Topic** (e.g. `Artificial Intelligence`, `Data Science`, `Cyber Security`, `Web Development`, `Python Full Stack`, `Cloud Computing`)
2. **Company / Provider Name** (e.g. `Infosys Springboard`, `Internshala`, `TCS`, `Cisco`, etc.)
3. **Start Date** (e.g. `03/08/2026`)
4. **Number of Days** (e.g. `30`, `60`, `90`, or `110`)

It automatically generates a high-quality, fully formatted `.docx` file inside the folder and `start.bat` will immediately detect it!

## Example Format Reference

Here is an example of what Day 1 and Day 2 look like:

```text
Day 1 -- 03 August 2026
Internship: Artificial Intelligence Intern -- Infosys Springboard
Work Summary: Reviewed internship syllabus, AI/ML objectives, workflow, deliverables, and set up the local Python development environment with Jupyter Notebook and virtual environment.

Learnings / Outcomes: Understood the machine learning lifecycle and how daily experiments will be documented and evaluated.
Blockers / Risks: Minor path configuration issues with pip were resolved through documentation.
Skills Used: Python, Machine Learning, Data Science

Day 2 -- 04 August 2026
Internship: Artificial Intelligence Intern -- Infosys Springboard
Work Summary: Practiced NumPy array manipulations, indexing, slicing, broadcasting, and vectorization operations for numerical computations.
Hours Worked: 5.5
Reference Links: https://springboard.infosys.com/student/learning
Learnings / Outcomes: Learned how vectorization drastically improves execution speed compared to standard Python loops.
Blockers / Risks: Understanding multi-dimensional array axis operations required testing with sample matrices.
Skills Used: Python, NumPy, Data Analysis
```
